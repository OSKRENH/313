# 313 — сайт дизайн-студии

Новая статическая версия сайта [go313.ru](https://go313.ru/), собранная без Tilda.

## Что изменено

- Все существующие разделы сохранены: главный экран, проекты, авторы, состав проекта, стоимость, контакты.
- Все проектные изображения собраны в одном разделе «Проекты».
- Проекты подгружаются порциями по мере прокрутки через `IntersectionObserver`.
- Каждый проект открывается в полноэкранной адаптивной галерее.
- Убрана отдельная длинная лента изображений, создававшая огромный скролл.
- Добавлены мягкие reveal-анимации и hover-эффекты без наложения элементов.
- Есть мобильное меню, адаптивная сетка и поддержка `prefers-reduced-motion`.

## Запуск

Откройте `index.html` или запустите любой статический сервер:

```bash
python -m http.server 8000
```

## Публикация в Cloudflare Pages

- Framework preset: `None`
- Build command: оставить пустым
- Build output directory: `/`
- Production branch: `main`

Изображения пока загружаются с существующего CDN Tilda, чтобы сохранить исходное качество и не раздувать репозиторий.
